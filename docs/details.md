# Equinox: подробности

Собственный торрент-клиент для Windows: демон на Go (движок anacrolix/torrent, без libtorrent),
веб-интерфейс и Windows-приложение с треем.

## Сборка

```powershell
# Версия для ПК: окно + трей, один файл без консоли, ключ вводить не надо
go build -ldflags "-H windowsgui -s -w" -o Equinox.exe ./cmd/equinox

# Серверная версия: без окна, сама открывает браузер со ссылкой, где уже есть ключ
go build -o Equinox-server.exe ./cmd/equinox-server

# Тесты
go test ./...
```

Данные (настройки, состояние, загрузки, копии .torrent, журнал) лежат в папке `data` рядом с программой.
Ключ доступа к API: `data/api-token`. Ни в одной версии его не нужно вводить: ПК-версия передаёт его окну сама, серверная открывает браузер по ссылке с ключом (браузер запоминает его) и запоминает работающий экземпляр в `data/ui-url`, так что повторный запуск просто открывает страницу.

## Устройство

| Папка | Что там |
|---|---|
| `internal/core` | движок-обёртка: раздачи, очередь, приоритеты файлов, перенос, рейтинг, расписание «черепахи» |
| `internal/store` | собственное файловое хранилище (штатное держит файлы через mmap и блокирует их на Windows) |
| `internal/portmap` | проброс порта UPnP / NAT-PMP с продлением и проверкой |
| `internal/api` | HTTP/JSON API на localhost с токеном |
| `internal/webui` | веб-интерфейс (HTML/CSS/JS, вшит в бинарник) |
| `cmd/equinox-server` | серверная версия: демон + веб-интерфейс без окна (`-state`, `-listen`, `-no-browser`, `-add`) |
| `internal/desktop`, `cmd/equinox` | окно WebView2, трей, автозапуск, регистрация magnet/.torrent |
| `cmd/mkicons`, `cmd/equinox/winres` | значок и манифест `.exe` (пересобрать: `go run ./cmd/mkicons`, затем `go-winres make` в `cmd/equinox`) |

## Управление списком

**Столбцы списка** настраиваются: правый клик по заголовку — галочки у нужных (размер, скачано и отдано за всё время, осталось, сиды и пиры, скорости, ETA (время до завершения), рейтинг, время раздачи, дата добавления, метка, папка). Статус и процент выведены прямо в полосу прогресса (зелёная — загрузка, синяя — раздача, жёлтая — проверка файлов, серая — пауза, красная — ошибка); отдельного столбца статуса нет. Заголовок можно перетащить, чтобы поменять порядок; Столбцы «#» и «Размер» всегда ровно такой ширины, какая нужна их содержимому (самый длинный текст и заголовок со стрелкой сортировки), и ничем не обрезаются; остальные делят оставшееся место. Первыми закреплены «#» (место в очереди загрузки: есть только у раздач, которые ещё качаются, и считается по порядку очереди независимо от фильтра и сортировки; у раздающихся пусто) и «Название»: их нельзя скрыть или переместить. Правый край заголовка тянется — так меняется ширина столбца (двойной клик возвращает ширину по умолчанию). Ширина левой панели меняется так же: полоска между ней и списком (150 px и до половины окна; стрелки влево/вправо в фокусе, двойной клик — 224 px). Высота нижней панели с подробностями меняется перетаскиванием полоски над ней (или стрелками вверх/вниз, когда она в фокусе; двойной клик — по умолчанию). Выбор запоминается в этом окне или браузере. Список всегда занимает всю ширину окна без горизонтальной прокрутки: ширины столбцов — это доли, они сами растягиваются и сжимаются вместе с окном, а не поместившийся текст обрезается многоточием. Тот же набор возможностей (правый клик по заголовку, перетаскивание, ширина, сортировка по клику) есть и в таблице пиров внизу; там можно включить ещё «Направление» и «Сеть».

Выбор: клик, Ctrl+клик, Shift+клик (диапазон). Кнопки панели действуют на все выбранные раздачи,
но только на видимые (при активном фильтре скрытые не затрагиваются). Сортировка: клик по заголовку столбца
(по возрастанию, по убыванию, сброс к порядку очереди).

| Клавиша | Действие |
|---|---|
| Ctrl+A | выбрать все видимые |
| Пробел | пауза / продолжить выбранные |
| Delete | удалить выбранные (с диалогом) |
| Esc | снять выделение |
| ↑ / ↓ (с Shift — расширить) | переместить выделение |
| / или Ctrl+F | открыть поиск (кнопка-лупа в верхней панели; Esc очищает запрос, второй Esc закрывает поле) |

## Добавление раздач

Кнопка «Добавить» (или перетаскивание .torrent в окно) открывает диалог со списком: в него можно собрать до 200 раздач: файлы .torrent, magnet-ссылки, infohash. Для каждой раздачи свои параметры:

- **Файлы** (для .torrent): дерево с галочками, «Все» / «Ничего», галочка на папке переключает всё внутри.
- **Параметры:** папка загрузки, «переместить завершённую в…», метка, добавить в паузе, приоритет первым и последним частям,
  последовательная загрузка, «Не проверять локальные файлы», заранее выделить место, число подключений.
- **«Применить ко всем»** копирует параметры выбранной раздачи на весь список; **«Сбросить»** возвращает умолчания;
  **«Сохранить как умолчание»** запоминает основные флаги для следующих добавлений.
- Если файлы раздачи уже лежат в папке загрузки, клиент сам проверяет их (в списке «Проверка файлов N%») и докачивает недостающее.
  «Не проверять» принимает их как целые без сверки хэшей.
- Ошибочные записи остаются в списке с причиной, остальные добавляются. Уже добавленные помечаются.
- У magnet-ссылки список файлов появится только после получения метаданных.
## Настройки

Окно настроек поделено на разделы слева: «Скорость» (единицы скорости — байты или биты в секунду, лимиты и расписание «черепахи»; единицы действуют в списке, таблице пиров, строке состояния, графике и в трее, лимиты скорости показываются и вводятся в тех же единицах: в списке и в настройках КБ/с, в режиме битов Кбит/с; хранятся они в КиБ/с, поэтому при вводе в битах значение округляется, например 1000 Кбит/с превратится в 999), «Загрузки» (папки, копии .torrent, резервирование места, «Добавлять торренты на паузе» — действует и для папки автодобавления, magnet-ссылок и командной строки), «Метки» (список меток: у каждой своё название и своя папка с кнопкой «Обзор…»; у метки есть цвет кружка, он назначается сам при создании (случайный из пяти цветов, которых нет среди цветов состояний: зелёный, синий, жёлтый, серый, красный; занятые другими метками пропускаются); метка может быть и без папки; метку, назначенную раздачам, можно удалить после подтверждения: раздачи окажутся без метки и попадут в «Без метки», это применится при сохранении настроек), «Очередь и раздача» (число одновременных загрузок и одновременных проверок локальных файлов, лишние проверки ждут очереди со статусом «Ждёт проверки» (проверки идут сверху вниз по порядку очереди, столбец «#»; если уменьшить число одновременных проверок, лишние проверки, у которых очередь ниже, сразу возвращаются в очередь и продолжатся с того места, где остановились; если переместить раздачу выше или ниже, она сдвинется и в очереди на проверку) (номер в очереди — в подсказке; такие раздачи не подключаются к пирам, пока не дойдёт очередь, иначе движок сам скачал бы описание раздачи и начал проверку в обход очереди); лимиты рейтинга и времени), «Сеть» (соединения и порт), «Уведомления» (только в приложении для ПК). Последний открытый раздел запоминается.

## Соединения

Настройки → «Соединения». Число подключений на раздачу применяется сразу (глобально и отдельно для раздачи на вкладке «Общее»).
DHT, PEX, uTP, TCP, IPv6, веб-сиды, приём входящих, шифрование и число попыток соединения движок читает только при запуске:
после сохранения появится полоса «нужен перезапуск» (в приложении с кнопкой «Перезапустить»).
Скорость ограничивается только для всего клиента: у движка нет лимитов скорости на отдельную раздачу.

## Дополнительно

- **Создание .torrent** (кнопка рядом с «Добавить»): из файла или папки, с трекерами, комментарием, размером части, флагом «приватный». Может сразу добавить раздачу и раздавать из папки с данными.
- **Папка автодобавления** (Настройки → Папки): файлы .torrent из неё добавляются сами и получают суффикс `.added` (не читаемые — `.failed`). Файл берётся, только когда перестал меняться, то есть дописан.
- **Переносить завершённые** в отдельную папку, папки для меток, перенос раздачи между папками и дисками.
- **Ошибки в списке:** нет места на диске или сбой записи останавливают раздачу и показывают причину; «Продолжить» повторяет попытку.
- **Порт:** если нужный порт занят другой программой или запрещён Windows, клиент выбирает свободный и пишет об этом в строке состояния.
- **Правый клик по раздаче** — то же меню действий, что на панели; «Показать в Проводнике».
- **Время раздачи:** Настройки → «Раздача» (и отдельно на вкладке «Общее» раздачи). Раздача останавливается по тому лимиту, рейтингу или времени, который достигнут раньше. Время считается, пока раздача завершена и не на паузе, и копится между запусками.
- **Уведомления Windows** (только версия для ПК, Настройки → «Уведомления»): когда загрузка завершена или раздача остановлена лимитом. Раздача, файлы которой уже лежали на диске, о «завершении» не сообщает.
- **Выбор папки** — собственное окно (одинаковое в приложении и в браузере, системное окно Windows не используется): быстрые ссылки (папка загрузок, рабочий стол, документы, диски с их названиями), путь по частям, кнопка «На уровень выше», создание папки, поле с путём, куда можно вписать путь вручную. Сервер отдаёт список папок только по ключу доступа.
- **Трекеры**: длинный адрес обрезается многоточием, по клику раскрывается в несколько строк.
- **Поиск** — кнопка-лупа в верхней панели: раскрывает поле, пока в нём есть запрос, поле остаётся открытым, а лупа подсвечена. Отдельной панели поиска под верхней больше нет; в узком окне рядом с лупой появляются выбор состояния и метки.
- **Заголовок окна** (название и кнопки сворачивания, разворачивания и закрытия) красится в цвета верхней панели интерфейса и следует за светлой или тёмной темой Windows. Кнопки остаются системными, поэтому работают привязка к краям экрана и перетаскивание. Полностью свои кнопки не делались.
- **Строка состояния:** слева точка порта (зелёная — порт открыт и есть входящие, жёлтая — проброшен, но входящих ещё нет, красная — недоступен) без текста, подробности появляются при наведении; рядом черепашка — режим ограничения скорости: левый клик включает и выключает (при включении она жёлтая), правый клик открывает маленькое окно с лимитами загрузки и отдачи для обычного режима и для «черепахи».
- **Уведомления в окне** сообщают о смене состояния раздачи один раз: проверка файлов закончилась или скачивающаяся раздача докачалась. Раздача, которая просто ждала очереди и оказалась готовой, ничего не показывает; если за раз закончилось три и больше проверок (например, сразу после запуска), выходит одна карточка со списком. Они выезжают карточками в правом верхнем углу: «Проверка завершена» (после настоящей проверки файлов, с результатом, если найдена только часть) и «Загрузка завершена». Пропадают сами через 7 секунд (не пока курсор на карточке), по крестику или по клику, который ещё и выделяет эту раздачу.
- **Файлы раздачи:** можно выбрать сразу несколько (клик, Ctrl+клик, Shift+клик диапазоном, Ctrl+A; выделение снимается кликом по пустому месту под строками или клавишей Esc) и задать им общий приоритет из списка над таблицей или из меню правой кнопки; если менять приоритет у файла, который входит в выбор, он применится ко всем выбранным. Меню правой кнопки по файлу также умеет «Показать в Проводнике» (файл подсвечивается в своей папке) и «Удалить с диском…»: выбранные файлы удаляются с диска после подтверждения и помечаются «Не скачивать», чтобы клиент не докачал их снова (раздача остаётся в списке). То же по клавише Delete и кнопке «Удалить…».
- **Журнал** `data\equinox.log` не растёт выше 5 МБ (прежний сохраняется как `.old`).

## Сборка и установка

```powershell
.\build.ps1              # проверки, тесты, сборка, установщик dist\Equinox-Setup-<версия>.exe (плюс копия Equinox-Setup.exe для уже установленных версий), архивы Equinox-pc-<версия>.zip и Equinox-server-<версия>.zip
.\build.ps1 -SkipTests
```

- **Equinox-Setup-\<версия\>.exe** — установщик для текущего пользователя (Inno Setup 6, права администратора не нужны): папка `%LOCALAPPDATA%\Programs\Equinox`, ярлык в меню «Пуск», по желанию значок на рабочем столе и автозапуск в трее. Данные лежат в `data` внутри папки программы; при удалении установщик спрашивает, удалять ли их (по умолчанию нет). Если Inno Setup не установлен, `build.ps1` пропускает этот шаг (`winget install JRSoftware.InnoSetup`).
- **Equinox-pc-\<версия\>.zip / Equinox-server-\<версия\>.zip** — портативные версии без установки; исполняемый файл внутри тоже с версией («Equinox 1.0.17.exe»), а установленная программа остаётся `Equinox.exe`.
- **Equinox-Setup.exe** — тот же установщик под прежним именем: уже установленные версии ищут в релизе именно этот файл, чтобы обновиться сами (`internal/update`). Новые версии сначала берут `Equinox-Setup-<версия>.exe`.
## Что не сделано

Проверка доступности порта извне (нужен внешний сервис, только по клику пользователя), доступ с других устройств
(нужны пароль и HTTPS), лимиты скорости на отдельную раздачу (движок не умеет),
перевод интерфейса, клик по уведомлению (он не открывает окно).
Не проверялись визуально: значок и меню в трее, установщик на вашей копии (проверен на копии скрипта с другим именем: установка, ярлык, запись об удалении, удаление), собственное окно выбора папки в приложении, открытие Проводника.
