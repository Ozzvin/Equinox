# Equinox

**A fast, lightweight BitTorrent client for Windows, written in Go.** Native window with a tray icon, a web interface, and no libtorrent.

Equinox — торрент-клиент для Windows: движок на Go ([anacrolix/torrent](https://github.com/anacrolix/torrent)), веб-интерфейс, вшитый в программу, и окно с треем. Работает как обычное приложение: скачали, запустили, ключи и настройки серверов не нужны.

## Возможности

- Раздачи по magnet-ссылкам и файлам `.torrent`, создание своих `.torrent`, папка слежения.
- Очередь загрузок, приоритеты отдельных файлов, последовательная загрузка, проверка файлов с ограничением числа одновременных проверок.
- Метки с собственными папками, поиск, настраиваемые столбцы списка, светлая и тёмная темы.
- Лимиты скорости, режим «черепаха» с расписанием, лимиты рейтинга и времени раздачи.
- Проброс порта UPnP / NAT-PMP, DHT, PEX, uTP, шифрование, IPv6.
- Уведомления Windows, автозапуск (в том числе тихий, в трее), открытие magnet-ссылок и `.torrent` по умолчанию.
- Собственное хранилище: файлы не блокируются для других программ, раздачу можно удалять и переносить на ходу.

## Установка

Скачайте нужный файл на странице [Releases](https://github.com/Ozzvin/equinox/releases):

| Файл | Что это |
|---|---|
| `Equinox-Setup-<версия>.exe` | установщик для текущего пользователя, права администратора не нужны |
| `Equinox-pc-<версия>.zip` | портативная версия для ПК: окно и трей, установка не нужна |
| `Equinox-server-<версия>.zip` | серверная версия без окна: интерфейс открывается в браузере |

В релизе есть ещё `Equinox-Setup.exe`: это тот же установщик под прежним именем, он нужен уже установленным
версиям, чтобы обновиться самим. Скачивать его вручную не нужно.

Требуется Windows 10/11 и Microsoft Edge WebView2 Runtime (есть в Windows 11 и в большинстве Windows 10; нужен только версии для ПК).

Данные (настройки, список раздач, копии `.torrent`, журнал) лежат в папке `data` рядом с программой. Чтобы перенести всё на другой компьютер, копируйте папку целиком.

> Сборки не подписаны, поэтому Windows SmartScreen может показать предупреждение при первом запуске: «Подробнее» → «Выполнить в любом случае».

## Сборка из исходников

Нужны Go 1.27+ и, для установщика, [Inno Setup 6](https://jrsoftware.org/isinfo.php).

```powershell
git clone https://github.com/Ozzvin/equinox.git
cd equinox
.\build.ps1              # проверки, тесты, сборка, установщик и архивы в папке dist
.\build.ps1 -SkipTests   # то же без тестов
```

Вручную:

```powershell
go build -ldflags "-H windowsgui -s -w" -o Equinox.exe ./cmd/equinox   # для ПК
go build -o Equinox-server.exe ./cmd/equinox-server                    # серверная
go test ./...
```

## Безопасность

API слушает только `127.0.0.1` и требует ключ доступа (`data/api-token`). Никому не показывайте этот файл. Доступ с других устройств пока не поддерживается.
